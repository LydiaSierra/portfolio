Selected Works

Flashcards App

Interactive web application for active recall and spaced-repetition learning

Problem & Objective: Self-directed learners need an intuitive, distraction-free study environment to organize card decks, test memory retention, and track learning progress without complicated backend overhead.

My Contribution: Designed the complete frontend architecture from the ground up, utilizing modern Angular Signals for reactive state and offline-first Local Storage persistence.

Key Technical Decisions:

  • Fine-grained reactivity with Angular Signals for smooth card state transitions without Zone.js overhead
  • Client-side Local Storage persistence preserving decks, cards, and study progress across sessions
  • Accessible keyboard controls allowing rapid card flipping, self-assessment, and deck traversal
  • Responsive, clean UI styled with utility-first Tailwind CSS, optimized for mobile and desktop screens
  • Angular
  • TypeScript
  • Signals
  • Tailwind CSS
  • Local Storage

GeDocs — Document Management

Centralized administrative tracking and document archive platform

Problem & Objective: Academic and administrative teams often experience lost documentation, misrouted approvals, and lack of searchable audit trails when handling files manually across departments.

My Contribution: Led the relational database schema design, RESTful controller architecture, and document lifecycle workflows as part of the SENA Software Analysis and Development capstone curriculum.

Key Technical Decisions:

  • Relational schema design in MySQL with normalized tables, foreign keys, and audit logging
  • RESTful backend architecture facilitating document registration, review stages, and status queries
  • Role-based access permissions separating administrative, reviewing, and standard contributor capabilities
  • Search filtering by category, date range, and status chips, with structured data export
